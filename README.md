# Shaik Althaf — Developer Portfolio

A modern, high-performance developer portfolio built with semantic HTML5, modern CSS3, and vanilla JavaScript. Features dark/light themes with 4 color accents, a custom interactive glowing cursor, typewriter effects, scroll animations, and a downloadable CV.

## 🚀 Live Sections
- **Hero**: Introduction, typing animations, quick stats, avatar with rotating orbit, and direct links to GitHub, LinkedIn, and CV download.
- **About**: CS background at Lovely Professional University, technical philosophies, and soft skills.
- **Skills**: Visual progress bars highlighting languages, frontend, backend, databases, and DSA.
- **Featured Projects**:
  - **BudgetX**: Real-Time Currency Converter & Budgeting Platform (Node.js, Express, MongoDB, JWT, Chart.js).
  - **Cartly**: E-Commerce & Admin Suite (React.js, Supabase, PostgreSQL, Role-Based Access).
- **Experience & Training**: Summer Training (DSA for Placements) & College Hackathon Coordinator.
- **Certifications**: Infosys (DBMS), Tech Veda (React.js), Great Learning (Python).
- **Education**: Lovely Professional University (B.Tech CSE), Sri Chaitanya Junior College, Sri Chaitanya High School.
- **Contact**: Direct email, phone, location details, and working message form.

## 🛠️ Tech Stack
- **HTML5 & CSS3**: Glassmorphism, CSS Custom Properties (Theme Switcher: Orange, Purple, Yellow, Green), Flexbox & Grid.
- **JavaScript**: Custom cursor tracking, IntersectionObserver animations, theme switcher with `localStorage` persistence.
- **Phosphor Icons**: High quality web icons.

## 📦 Deployment Options

### 1. GitHub Pages
1. Push this folder to a GitHub repository (e.g., `Althaf-1717/portfolio`).
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/root`, then click **Save**.

### 2. Vercel / Netlify
- Drag and drop this folder into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
